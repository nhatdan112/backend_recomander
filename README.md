# Mobile Recommendation Backend Server

Backend API for the **Mobile Recommendation Application**, built to provide authentication, recommendation services, and data management for the mobile client.

## Features

- User authentication
- Recommendation engine
- RESTful API
- Database integration
- Scalable backend architecture

## Tech Stack

- Node.js
- Express.js
- MongoDB
- JWT Authentication
